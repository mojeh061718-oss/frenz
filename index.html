Settings

Provider — Grok

One model, two routes: paste an xAI key, or an AWS Bedrock key if that's where your credits are. Whichever one is keyed is the one that answers. There is no failover behind it on purpose — a pool used to swap in a weaker model whenever Grok hiccuped, and the only thing you'd notice was that she started writing badly. If Grok can't be reached now, you get a plain error in the corner instead.

Time

The app runs on real time — her clock, night looseness, openers, and due-date follow-ups all track it. Skip ahead when you don't want to wait for tonight. Time only moves forward.

Your data

All friends, conversations, and each friend's private impressions of you are saved automatically on this device.

The archive is one readable document: full transcripts with reference numbers, each friend's private state changes inline, and automatic quality checks. When a conversation feels off, download this and share it when asking for help — no API usage.

frenz is a private, local-first app. Nothing is uploaded anywhere except your messages to the Claude API using your own key.
